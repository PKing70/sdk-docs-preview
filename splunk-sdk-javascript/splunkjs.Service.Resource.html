Class: Resource

splunkjs.Service.Resource()

new Resource()

Provides a base definition for a Splunk resource (for example, an entity such as an index or search job, or a collection of entities). Provides basic methods for handling Splunk resources, such as validation and accessing properties. This class should not be used directly because most methods are meant to be overridden.
