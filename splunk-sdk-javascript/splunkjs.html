Namespace: splunkjs

splunkjs

The Splunk SDK for JavaScript. Doc-only declaration. The SDK attaches its classes to a `splunkjs` root that JSDoc cannot infer from the module/closure idiom the source uses, so the namespace is declared explicitly here. Without this, JSDoc resolves all 37 classes correctly in its doclet graph but the template renders no pages for them, because their `memberof` chain roots at an undocumented container.
